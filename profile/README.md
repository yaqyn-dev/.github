## Engineering approach

- **Start with the workflow.** Define who records a request, who acts on it, and what the next person needs to know.
- **Make state explicit.** Account for validation, permissions, failed actions, and the records left behind.
- **Verify the result.** Review changes, run relevant checks, and inspect the complete user journey before describing work as finished.
