# Montserrat font source

Source: [Google Fonts Montserrat](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/montserrat), commit `47d54ca1ebb14fd864695f1d39dc734f39017c33`.

Original file: `Montserrat[wght].ttf`, stored unchanged as `Montserrat-wght.ttf`.
SHA-256: `0f7b311b2f3279e4eef9b2f968bcdbab6e28f4daeb1f049f4f278a902bcd82f7`.

Copyright and license are preserved in `OFL.txt`. The font is distributed under the SIL Open Font License 1.1. Do not replace its attribution with owner-credit image metadata.

The renderer selects weight 700 for the wordmark and contact address, and 500 for supporting text, using the original variable font's weight axis. Visitors do not download a web font; the rendered assets contain the final typography.
